# Sistema de Cadastro de Usuários
 
Aplicação web desenvolvida como atividade acadêmica,
utilizando o padrão MVC.
 
## Tecnologias
 
-HTML5
-CSS3: 
-JavaScript
-API ViaCEP


-Java 17
-Jakarta Servlet 6.0
-Gson
-JDBC
-MySQL
-SQL

 
## Funcionalidades
 
- Cadastro de usuários
- Listagem de usuários
- Edição de usuários
- Exclusão de usuários
- Validação dos campos
- Busca automática de endereço através do CEP
 
## Estrutura
 
O projeto utiliza o padrão MVC:
 
- Model: representa os dados dos usuários.
- View: interface gráfica da aplicação.
- Controller: recebe e processa as requisições.
- DAO: realiza a comunicação com o banco de dados.
 
## Banco de Dados
 
O script de criação do banco está disponível em:
 
banco/banco.sql
 
## Execução
 
1. Instalar Java.
2. Instalar Maven.
3. Instalar MySQL.
4. Criar o banco utilizando o arquivo banco.sql.
5. Configurar usuário e senha do MySQL no arquivo Conexao.java.
6. Executar o projeto através de um servidor Tomcat.
